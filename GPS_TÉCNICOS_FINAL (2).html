⚙️ Publicar directo en GitHub

Si completás esto, el botón "Guardar en historial" va a subir los archivos directo a tu repo, sin descargar ni arrastrar nada. Se guarda solo en este navegador — no lo completes en compus que no sean tuyas.
¿Cómo saco el token? En GitHub: foto de perfil (arriba a la derecha) → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token. Elegí SOLO el repo gpstecnicos (no "todos los repos"), y en Permissions activá Contents: Read and write. Copiá el token generado y pegálo acá arriba — GitHub solo te lo muestra una vez.

🔑 Conexión con base NAP

Con esto, el buscador de cliente NAP funciona directo desde el dashboard. Se guarda solo en este navegador, nunca en el archivo — no lo completes en compus que no sean tuyas.

📱 Instalar la app

En iPhone, Apple no deja instalar con un solo botón. Son 3 pasos:

1. Tocá el ícono de compartir (el cuadrado con la flecha hacia arriba), abajo al centro de Safari.
2. Deslizá la lista hacia abajo y tocá "Agregar a inicio".
3. Tocá "Agregar" arriba a la derecha.

Listo, te queda el ícono en la pantalla de inicio como cualquier app.

👥 Agregar técnico a la base

Se guarda en este navegador y queda disponible para próximos reportes sin volver a escribirlo. Cuando completes el Excel, escribí el apellido y nombre igual que acá para que el dashboard lo reconozca automáticamente.
